# Raw Sources

Immutable source documents for the Pike knowledge base. The LLM reads from these but never modifies them. This is the source of truth.

## Structure

```
raw/
  README.md          — this file
  manifest.md        — catalog of all source documents with metadata
  assets/            — downloaded images, diagrams (local copies)
```

## Source Types

| Type | Description | How Added |
|------|-------------|-----------|
| Pike manual | Official Pike 8.0 reference documentation | Web clipper, manual dump |
| Stdlib source | `.pike` / `.pmod` files from Pike distribution | Copied from installed Pike |
| Test output | Runtime verification results from `pike -e` | Generated by `factcheck` pipeline |
| RFC / proposal | Language design discussions | Web clipper |
| Blog / article | Community-written Pike content | Obsidian Web Clipper |
| Issue / thread | GitHub issues, mailing list threads | Manual copy |

## Adding Sources

1. Drop the file into `raw/` with a descriptive name (kebab-case)
2. Update `manifest.md` with the entry
3. Tell the LLM to ingest — it will read the source, integrate into the wiki, and log the event

## Conventions

- Files are never modified after being added (append-only)
- Use descriptive filenames: `pike-8.0-array-module.md`, not `doc1.md`
- Images go in `raw/assets/` and are referenced by relative path
